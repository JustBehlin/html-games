# Mini Games

Six tiny browser games and toys. Single HTML files, no install, no dependencies. Open any file in a browser or host them with GitHub Pages.

| File | What it is | How to play |
|---|---|---|
| `pond.html` | Tiny Pond | Tap or drag to make ripples. Ducks float around and get pushed by the waves. |
| `constellations.html` | Night Sky | Tap to place stars. They connect into constellations. |
| `snake.html` | Snake | Swipe or use arrow keys / WASD. |
| `pixel.html` | Pixel Paint | Pick a color and paint on a 16x16 grid. |
| `gravity.html` | Gravity Balls | Tap or drag to drop balls. Flip gravity with the button. |
| `jet.html` | Sky Gunner | Aim the fixed gun, hold to fire, shoot jets and bombers and dodge their bombs. |

All pages follow your device's light or dark mode.

## Run locally

Double-click any `.html` file.

## Host on GitHub Pages

1. Settings -> Pages
2. Source: Deploy from a branch -> `main` -> `/ (root)`
3. Open `https://JustBehlin.github.io/html-games/snake.html`
